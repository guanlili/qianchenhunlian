# 门店管理员使用指引（手机 + 电脑）

> 面向门店店长/红娘的日常操作说明。原则：**日常操作用手机，重录入用电脑**。
> 手机端（390px 视口）以下全部路径已于 2026-08 实测通过（见 PR #30）。
>
> 📌 用户可见版本已内置后台「使用指引」页（`admin/src/routes/_layout/guide.tsx`，
> 侧边栏底部入口，所有角色可见）。修改本文时请同步更新该页面，两边内容保持一致。

## 登录

- 网址：`https://dashboard.qianyuan.website`（手机电脑都用这个）
- 账号密码由总部（系统管理员）开通，找总部要
- 手机推荐用浏览器（Safari / Chrome）打开，并**添加到主屏幕**，以后一点就进

## 手机端日常操作（推荐）

| 场景 | 操作路径 |
| --- | --- |
| 查会员 / 看资料和联系方式 | 会员管理 → 点任意一行进 360° 详情（整行可点） |
| 实名认证 | 会员详情 → 「实名认证」一键通过 |
| 开通 / 续费会员 | 会员详情 → 「开通会员」→ 选套餐（体验周卡 / 月卡 / 年卡）→ 确认发放 |
| 处理撮合工单 | 撮合工单 → 待处理工单 → 处理 |
| 看本店经营数据 | 工作台 |

说明：

- 手机上菜单在左上角 ☰（汉堡按钮），点开即是各功能入口
- 会员表格字段多时可以左右滑动，不影响操作
- 会员到期续费：再次点「续费会员」选套餐即可，时间自动往后接

## 电脑端操作（重录入场景）

| 场景 | 原因 |
| --- | --- |
| 新会员建档（代录资料） | 几十个字段的长表单，电脑录入效率高 |
| 择偶要求、父母信息编辑 | 同上 |
| 批量筛选、会员管理 | 大屏看全字段方便 |

以上入口在手机上也能打开（弹窗内滚动填写），只是体验一般，建议电脑。

## 常见问题

- **手机上点开「代录资料」发现字段很多？** 属正常，建议换电脑操作。
- **登录提示无权限？** 账号可能未分配门店或被停用，找总部检查员工账号配置。
- **看不到某会员？** 门店管理员只能看本店会员（资料归属门店决定），跨店资料找总部。
